Pola Bilangan

Tujuan Pembelajaran: Mengidentifikasi, menentukan, dan memprediksi pola susunan benda dan bilangan serta menyelesaikan permasalahan yang terkait.

Yang akan kamu kuasai: mengenali pola susunan benda, menentukan rumus suku ke-n barisan aritmetika dan geometri, serta memprediksi suku berikutnya.

Sub-bab 1 · Memahami

Pola Susunan Benda

Pola adalah keteraturan yang berulang. Susunan kelereng, ubin, atau kursi bioskop bisa membentuk pola bilangan: 1, 3, 6, 10, … (pola segitiga) atau 1, 4, 9, 16, … (pola persegi).

▲

Pola segitiga

1, 3, 6, 10, 15, … Rumus: Un = n(n+1)/2.

■

Pola persegi

1, 4, 9, 16, 25, … Rumus: Un = n².

▬

Pola persegi panjang

2, 6, 12, 20, 30, … Rumus: Un = n(n+1).

Visual pola titik

Pilih polanya, geser nomor sukunya, dan lihat titik-titiknya tersusun.

Sub-bab 2 · Mengaplikasi

Barisan Aritmetika

Barisan aritmetika punya beda (b) yang tetap antar suku berurutan: 3, 7, 11, 15, … (b = 4). Rumus suku ke-n: Un = a + (n − 1)b, dengan a suku pertama.

Kalkulator suku ke-n aritmetika

Masukkan suku pertama (a), beda (b), dan nomor suku (n).

Latihan: barisan aritmetika — tentukan suku yang diminta

Jawab satu per satu dengan tombol Cek di tiap soal. Pembahasan langkahnya muncul setelah kamu menjawab.

1) 3, 7, 11, … Suku ke-10 = …

2) 5, 9, 13, … Suku ke-8 = …

3) 2, 6, 10, … Suku ke-12 = …

4) 10, 7, 4, … Suku ke-9 = …

5) 1, 4, 7, … Suku ke-15 = …

Sub-bab 3 · Mengaplikasi

Barisan Geometri

Barisan geometri punya rasio (r) yang tetap: tiap suku diperoleh dengan mengalikan suku sebelumnya dengan r. Contoh: 2, 4, 8, 16, … (r = 2). Rumus: Un = a × r^(n−1).

Kalkulator suku ke-n geometri

Masukkan suku pertama (a), rasio (r), dan nomor suku (n).

Latihan: barisan geometri — tentukan suku yang diminta

Jawab satu per satu dengan tombol Cek di tiap soal. Pembahasan langkahnya muncul setelah kamu menjawab.

1) 2, 4, 8, … Suku ke-7 = …

2) 3, 9, 27, … Suku ke-5 = …

3) 5, 10, 20, … Suku ke-6 = …

4) 1, 3, 9, … Suku ke-6 = …

5) 4, 8, 16, … Suku ke-8 = …

Sub-bab 4 · Mengaplikasi

Pola Bilangan Khusus

Beberapa pola punya nama sendiri: Fibonacci (tiap suku = jumlah dua suku sebelumnya: 1, 1, 2, 3, 5, 8, …), bilangan segitiga, bilangan persegi, dan bilangan kubik (1, 8, 27, 64, …).

Fibonacci di alam

Jumlah kelopak bunga, spiral cangkang, dan susunan biji bunga matahari mengikuti pola Fibonacci: 1, 1, 2, 3, 5, 8, 13, 21, 34, … Suku berikutnya selalu jumlah dua suku sebelumnya.

Tantangan: pola 1, 8, 27, 64, … adalah bilangan kubik (n³). Suku ke-6 = 6³ = 216. Pola 2, 6, 12, 20, … adalah pola persegi panjang: Un = n(n+1), suku ke-6 = 42.

Cara menemukan rumus pola

  1. Hitung selisih antar suku. Kalau tetap → aritmetika.
  2. Hitung rasio antar suku. Kalau tetap → geometri.
  3. Kalau selisihnya berubah teratur, coba pola kuadrat (n², n(n+1), …).
  4. Uji rumusmu pada suku yang sudah diketahui sebelum memprediksi.
Sub-bab 5 · Mengaplikasi

Memprediksi Pola dalam Kehidupan Sehari-hari

Kursi bioskop bertambah 3 tiap baris, tumpukan kaleng membentuk segitiga, tabungan berbunga berlipat — semua bisa diprediksi dengan pola bilangan.

Cerita: kursi bioskop

Baris pertama 8 kursi, tiap baris berikutnya 3 kursi lebih banyak. Baris ke-10: U10 = 8 + 9×3 = 35 kursi. Berapa kursi di baris ke-20? U20 = 8 + 19×3 = 65 kursi.

Latihan: prediksi pola

Jawab satu per satu dengan tombol Cek di tiap soal. Pembahasan langkahnya muncul setelah kamu menjawab.

1) Tumpukan kaleng pola segitiga: baris ke-7 ada … kaleng.

2) Tabungan berlipat 2 tiap tahun dari Rp100.000. Tahun ke-5: Rp… ribu.

3) Pola 5, 10, 15, 20, … Suku ke-12 = …

4) Pola 100, 90, 80, … Suku ke-8 = …

5) Pola persegi panjang 2, 6, 12, 20, … Suku ke-6 = …

Rangkuman A.4

  • Pola segitiga: Un = n(n+1)/2. Pola persegi: Un = n². Pola persegi panjang: Un = n(n+1).
  • Barisan aritmetika: beda tetap, Un = a + (n−1)b.
  • Barisan geometri: rasio tetap, Un = a × r^(n−1).
  • Fibonacci: tiap suku = jumlah dua suku sebelumnya.
  • Temukan dulu aturannya (beda/rasio/rumus), baru prediksi suku berikutnya.
